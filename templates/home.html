How it works
  1. You paste a link. We check that it's an http or https address and add https:// if you left it off.
  2. We give it a random 6-character code and store the pair in a database.
  3. Pasting the same link again returns the same code, so nothing is stored twice.
  4. Anyone who opens the short link is sent straight to the original.
